왜 SolaNavi인가

햇빛소득마을 공모,
왜 어려울까?

2026 행안부 공모는 마을·협동조합·발전사업 세 영역의 복합 컨설팅이 필요합니다. 대부분 컨설턴트는 매번 자료를 처음부터 찾고, 서식을 새로 작성합니다.

😩 기존 방식의 문제

  • STEP별 자료가 흩어져 있어 처음 찾기 어려움
  • 마을마다 회의록·동의서·사업계획서를 매번 새로 작성
  • 수익성 계산을 엑셀로 일일이 — 마을 설득 자료 부족
  • 법령·정관 조항 매번 검색해서 확인
  • 마을 진행 단계 관리가 머릿속에만
  • 외근·현장에서는 PC가 없으면 작업 불가

✨ SolaNavi의 해결

  • STEP 1~7 매뉴얼 + 단계별 체크리스트 자동 안내
  • 회의록·동의서·사업계획서 AI 5초 작성 (Claude AI)
  • 전국 250개 시군구 일조 데이터 자동 적용 — 20년 누적 시뮬
  • 법령 조문 AI 검색 + 정관(안) 표준예시문 탑재
  • 마을별 D-day·진행단계·담당자 통합 관리
  • 모바일 완벽 대응 — 현장에서 즉시 입력·조회
핵심 기능

한 명이 마을 5~10곳을 동시에

10개 도구가 STEP별 컨설팅을 자동화합니다.

📖
STEP 1~7 매뉴얼
첫 방문 설득부터 협동조합 운영까지 50+ 페이지 완전 가이드. 표준정관(안) 102조 탑재.
🤖
AI 서류 자동 작성
회의록·동의서·사업계획서·공문 등을 Claude AI가 5초 만에 작성. Word·HWP·PDF 다운로드.
💰
수익성 시뮬레이션
설치 용량·일조시간·SMP·REC를 입력하면 20년 누적 수익 자동 계산. 주민 설명회용 PDF.
🗺
전국 시군구 DB
17개 시도 + 250개 시군구 평년 일조시간. 시도 선택 시 시군구 자동 필터.
🎙
실시간 녹음 + AI
마을 회의 현장에서 녹음 → AI가 공식 회의록 자동 정리. 모바일 직접 녹음 지원.
⚖️
법령 AI 검색
신재생에너지법·협동조합기본법·전기사업법 조문 자연어 검색.
📊
마을 통합 대시보드
담당 마을의 STEP 단계·D-day·준비도를 한 화면에. Excel·CSV 내보내기.
🔍
부실 조기경보
공고문 5대 필수 요건 자동 점검 + 갈등 매트릭스 + 시나리오 시뮬.
📱
모바일 완벽 대응
현장에서 핸드폰으로 마을 정보 입력·서류 조회·녹음. 어디서나 동기화.
사용 흐름

3단계로 끝나는 컨설팅 시작

1

로그인 → 마을 등록

발급받은 라이선스 키로 로그인 후, 담당 마을의 기본 정보(이름·이장·주민수)를 입력합니다. 첫 방문 일정도 함께 등록.

2

STEP별 컨설팅 진행

매뉴얼 STEP 1~7을 따라가며, 필요할 때마다 AI 도구로 회의록·동의서·사업계획서를 자동 작성합니다.

3

제출 → 결과 관리

준비도 진단 통과 후 공모 서류를 제출. 선정 후 운영 단계도 동일한 도구로 계속 관리합니다.
