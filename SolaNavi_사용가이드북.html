SolaNavi 사용 가이드북 ☀

햇빛소득마을 공모 컨설팅을 처음 시작하는 컨설턴트를 위한 안내서. 로그인부터 AI 서류 작성, 결제·구독 관리까지 단계별로 설명합니다.

📘 가이드북 소개

이 가이드는 솔라나비를 처음 사용하는 컨설턴트가 30분 안에 핵심 기능을 익힐 수 있도록 만들어졌습니다.

읽는 순서:

  1. 시작 — 로그인부터 첫 마을 등록까지 (10분)
  2. 컨설팅 매뉴얼 — STEP 1~7 따라가는 법 (필요할 때 참조)
  3. 업무도우미 AI — 자주 쓰는 도구들 (활용 빈도순)
  4. 구독·결제 — 플랜 선택과 사용량 관리
  5. 문제 해결 — 막힐 때 참고
💡 팁: 좌측 사이드바에서 원하는 항목으로 바로 이동할 수 있어요. 모바일에서는 우측 상단 "📖 목차" 버튼을 누르세요.

🔑 로그인하기

솔라나비는 라이선스 키 기반 로그인입니다. 이메일/비밀번호 없이 한 줄짜리 키로 즉시 입장합니다.

1접속: 브라우저에서 https://w1nter1052.github.io/solanavi/SolaNavi.html
2라이선스 키 입력: 마을항해에서 발급받은 키 (예: SNV-PRO-XXXXXX-XXXXXX-XXXXXX) 붙여넣기
3입장하기 클릭 — 끝!
ℹ️ 키가 없으신가요? 우측 "🆓 무료 체험" 버튼으로 무료 키를 받거나, "📋 구독 안내"에서 유료 플랜을 신청하세요.

한 번 입장하면 자동 로그인

같은 기기/브라우저에서는 다시 키를 입력할 필요 없이 바로 입장합니다. 다른 사람과 PC를 공유한다면 사용 후 반드시 로그아웃하세요.

⚠️ 보안: 라이선스 키는 비밀번호와 같습니다. SNS·카톡·공개 메일에 노출 X. 분실 시 즉시 마을항해(sadad1052@naver.com)에 문의해 재발급받으세요.

🏘 첫 마을 추가하기

로그인 후 가장 먼저 할 일은 담당 마을 등록입니다. 마을 정보가 있어야 AI 도구들이 작동합니다.

1상단 "⚡ 업무도우미 AI" 탭 클릭
2"+ 마을 추가" 버튼 클릭 (대시보드 첫 화면)
3마을명·소재지·이장·주민수 입력 → 저장
4등록 후 자동으로 대시보드의 "컨설팅 마을"에 선택됨
✅ 다음에 다시 들어올 때: 마지막으로 선택했던 마을이 자동 복원됩니다. 다시 선택할 필요 없어요.

📖 컨설팅 매뉴얼 둘러보기

상단 "📖 컨설팅 매뉴얼" 탭으로 이동하면 좌측 사이드바에 STEP 1~7과 보조 자료가 펼쳐집니다.

STEP주요 내용핵심 도구
STEP 1 · 첫 방문마을 설득, 사업 소개, 기대 효과수익성 계산기 · 기초정보 입력
STEP 2 · 주민 조직마을회 규약, 총회 안건, 70% 동의주민 동의서 · 의결서 AI
STEP 3 · 협동조합 설립정관 작성, 설립신고, 등기표준정관(안) 102조 · 정관 AI
STEP 4 · 발전소 준비부지·계통 확인, 시공업체 선정부지 점검 · 자부담 금융
STEP 5 · 공모 신청서식 1~4 작성, 제출사업계획서 AI · 신청서 자동 채우기
STEP 6 · 발전소 건설금융 조달, 인허가, PPA 체결REC 가중치 · 고정가격 계약
STEP 7 · 협동조합 운영수익 배분, 마을 기금 관리배분 계산 · 운영 핸드북

STEP 1 — 첫 방문 가이드

마을에 처음 가서 사업을 소개할 때 사용합니다.

  • ☀️ 햇빛소득마을이란? — 사업 개요를 한 페이지로 보여주기
  • 🌾 왜 우리 마을에 필요한가 — 마을 입장에서 본 이익
  • 📋 사업 진행 절차 — 7단계 전체 로드맵
  • 📈 기대 효과 및 성과 — 발전량·수익·CO₂ 절감 시뮬
  • 💰 수익성 계산기 — 마을 맞춤 수익 계산 + 주민 설명용 PDF
  • 📝 마을 기초정보 입력 — 사업계획서에 들어갈 마을 데이터 사전 정리

💰 수익성 계산기 사용법

마을의 예상 수익을 시뮬레이션해서 주민 설득 자료로 활용합니다.

  1. 지역 선택: 17개 시도 중 선택 → 시군구 자동 필터링 → 일조시간 자동 입력
  2. 설치 용량 슬라이더: 100kW ~ 5MW 사이 조정 (일반 500kW 권장)
  3. SMP·REC 단가: 현재 시장가 (기본값 사용 권장)
  4. REC 가중치: 햇빛소득마을은 1.2 (+0.2) 선택
  5. 배분 비율: 마을공동기금 40% + 취약계층 40% + 유지보수 10% + 관리비 10%
  6. 스크롤 아래 20년 누적 수익 시뮬레이션 자동 표시
  7. 하단 📝 수익성 리포트 Word / 🇰🇷 한글 / 🖨 주민설명회용 시각 PDF 중 하나 다운로드
💡 팁: 주민설명회용 시각 PDF는 차트가 큼지막하게 들어가서 회의장에서 빔프로젝터로 띄울 때 좋습니다.

📜 협동조합 정관 작성

STEP 3에서 협동조합 설립 시 가장 중요한 문서입니다.

  1. 좌측 메뉴 STEP 3 → 정관 작성 클릭
  2. 🪄 마을 정보로 채우기 클릭 → 미리 입력한 마을 데이터가 자동 삽입
  3. 각 조문 검토 후 마을 특성에 맞게 수정
  4. ⬇ Word / 한글 / PDF 다운로드 → 창립총회 의안으로 사용
⚠️ 법적 효력: SolaNavi가 제공하는 정관은 참고용 표준 예시문입니다. 최종 제출 전 반드시 변호사 또는 법무사 검토를 받으세요.

🏠 업무도우미 대시보드

상단 "⚡ 업무도우미 AI" 탭 첫 화면. 모든 마을의 상태를 한눈에 봅니다.

화면 구성

  • 마을 선택 드롭다운: 작업할 마을을 선택. 한 번 선택하면 다음에도 기억
  • KPI 4개: 관리 마을 수 · 신청 가능 마을 · D-day · 생성 문서 수
  • 도구 모음: 일정 캘린더 / 인허가 타임라인 / 조합 비교 / 운영 핸드북 / 자가진단 / Excel·CSV 내보내기 / 감사 로그 / 구독 플랜
  • 빠른 실행: 회의록 작성 · 서류 검토 · 사업계획서 · 법령 검토 · 수익 분석 · AI 상담
  • 2026 공모 일정: 1차 마감 (5.31) / 1차 결과 (7.31) / 2차 마감 (7.31) 등

🏘 마을 관리

두 번째 탭. 마을 추가·수정·삭제·정보 채우기.

새 마을 추가

  1. + 새 마을 추가 카드 클릭
  2. 이름·소재지·이장명·주민수·가구수 입력
  3. 현재 STEP 단계 선택 (예: STEP 1 첫 방문)
  4. 저장 → 자동으로 대시보드에 표시

기초정보 자동 채우기

마을 카드 클릭 → "기초정보 입력" 버튼 → 상세 정보 25개 항목 입력. 이 정보는 정관·사업계획서 등에 자동 활용됩니다.

마을 데이터 내보내기

버튼용도

📄 CSV (텍스트)노션·구글시트 등 다른 도구로 가져갈 때
⬇ 내보내기 (JSON)다른 PC로 옮길 때 백업

📄 서류 AI 작성

회의록·동의서·사업계획서·공문 등을 AI가 자동 작성합니다.

4가지 STEP별 서류

  • 📣 STEP 1 — 설득 자료: 진행 보고서 · 공문 초안 · 마을 공고문
  • 🏛 STEP 2 — 주민총회·동의: 총회 의사록 · 주민 동의서 · 마을회 공고문
  • 🤝 STEP 3 — 협동조합: 정관(안) · 창립총회 의사록 · 발기인 명부
  • 📋 STEP 4 — 신청·사업계획서: 서식 1~4 자동 작성

사용 흐름

1상단 STEP 선택 (예: STEP 2)
2문서 종류 선택 (예: 총회 의사록)
3왼쪽 입력 양식 채우기 (회의 날짜·안건·결과 등)
4🤖 AI로 작성 버튼 클릭 → 5초 후 완성
5편집 → 📋 복사 / ⬇ TXT / ⬇ Word / 🖨 인쇄
💡 녹음 활용: 회의록은 현장 녹음을 텍스트로 변환한 뒤 AI에 넣으면 가장 정확합니다. 회의록 녹음 참고.

🎙 회의록 녹음 + AI

회의 현장에서 직접 녹음하거나 텍스트로 정리한 후 AI가 공식 회의록 양식으로 변환합니다.

모바일 실시간 녹음

  1. 업무도우미 → 🎙 회의록 탭
  2. "실시간 녹음" 모드 선택
  3. 큰 마이크 버튼 누르면 녹음 시작
  4. 회의 종료 후 다시 버튼 누르면 자동으로 텍스트 변환 (Whisper AI)
  5. AI 작성 버튼 → 공식 회의록 자동 정리

PC에서 파일 업로드

  1. 녹음 파일(.mp3/.m4a/.wav) 또는 회의 메모(.txt/.docx) 업로드
  2. 자동으로 텍스트 추출
  3. AI 작성 → 결과 다운로드

⚖️ 법령 검색

신재생에너지법·협동조합기본법·전기사업법 조문을 자연어로 검색합니다.

예시 질문:

  • "마을 자치규약에 협동조합 조항이 없으면 어떻게 해야 하나요?"
  • "REC 가중치 +0.2를 받으려면 어떤 조건이 필요한가요?"
  • "마을총회 의결 정족수는 어떻게 정해지나요?"

AI가 관련 법령 조문 + 햇빛소득마을 공고문 기준으로 답변합니다.

💬 AI 상담

매뉴얼·법령·서식 모든 영역에 대한 자유 질문. 컨설팅 중 막힐 때 활용.

  • 예: "STEP 3 정관에서 수익 배분 조항을 어떻게 써야 할까요?"
  • 예: "주민 70% 동의 받기 어려운 경우 대안은?"
  • 예: "공고문 마감일 D-7인데 정관 등기가 안 끝났어요. 어떻게 해야 할까요?"

💡 예시: PRO · 234/3000 잔여 2766 — PRO 플랜 / 이번 달 234회 사용 / 한도 3000회 / 잔여 2766회

칩 클릭 시 상세 모달이 열려 AI 호출·회의록 STT 분 등을 진행 바로 확인 가능합니다.
